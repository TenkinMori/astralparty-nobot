## NoBot v1.4 自动识别工具

游戏更新后不用再手算热更包大小。

### 新增 `tools/nobot_tool.py`
一条命令完成：找游戏目录 → 按**内容**找当前热更 `__data` → 读大小 → 打补丁 → 重建 `hid.dll`（保留其它服务器 payload）→ 装进游戏根目录（备份旧 `hid.dll`）。

```powershell
python tools\nobot_tool.py --install
```

或者把游戏文件夹拖到 `一键生成NoBot.bat` 上。

- `--no-patch`：只按检测到的尺寸重建，不重新打补丁
- `--out <路径>`：指定输出
- `--keep-all`：保留 stub 里全部旧 payload
- 内置 `tools\dllpatch`（.NET 9）与 `tools\nobot_patch.json`，不再依赖 PatchManager / Extra 工程

### 附件
- `hid.dll`：成品，国服 `8,405,676` / 国际服 `8,276,448`（NBP2 双 payload）
- `nobot_tool.zip`：独立工具包（`nobot_tool.py` + `dllpatch` + stub + bat + 说明）
  - 需要 Python 3.10+、UnityPy、.NET 9 运行时

### 验证
- 工具自动识别到国服 `8,405,676`，输出两处 ConstSwap（`UI.RoomWaitPanel` 的 `<RequsetStart>b__16_0/1`）
- `%TEMP%\nobot.log`：`hook installed` / `redirect __data`
- 游戏正常进登录界面；开房点「开始」直接开局，不弹补 Bot
