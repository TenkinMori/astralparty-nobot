# NoBotStarter

开房间不补 Bot，点「开始」直接开局。

---

## 使用方法

**双击 启动.bat**，选 `1. 安装`。

装完启动游戏 -> 创建房间 -> 点「开始」-> 直接开局，不再弹「是否补充 Bot」。

---

## 菜单说明

| 选项 | 作用 |
|---|---|
| 1. 安装 | 打补丁并安装到游戏 |
| 2. 还原原版 | 恢复游戏原样 |
| 3. 查看状态 | 看当前装了什么 |

---

## 它会改什么

只改游戏补丁包里的两个常量：

```
UI.RoomWaitPanel.<RequsetStart>b__16_0   ldc.i4.1 -> ldc.i4.0
UI.RoomWaitPanel.<RequsetStart>b__16_1   ldc.i4.1 -> ldc.i4.0
```

这两个分别是「补 Bot 开局」和「不补 Bot 开局」两个按钮的处理函数。
把 true 改成 false 后，两个按钮都走「不补 Bot」分支。

不影响任何其他功能。

---

## 出问题怎么办

| 问题 | 解决 |
|---|---|
| 装了没效果 | 菜单选 3 查看状态，确认 SHA256 变了 |
| 游戏起不来 | 菜单选 2 还原原版 |
| 游戏更新后失效 | 重新选 1 安装 |

---

## 还原原版

菜单选 2 还原原版。原版备份存在 __data.apa-orig，首次安装时自动创建。

---

## 注意事项

不要和其他改补丁包的插件同时使用。
如果别的插件也修改了游戏补丁包，两个插件会互相覆盖。
需要同时使用时，请用完整的补丁管理器 PatchManager 统一合并。
